# Pencil Tic-Tac-Toe

Tic-tac-toe drawn in pencil on graph paper. Single HTML file, no build step, no dependencies.

**Play it:** https://denis-code-collab.github.io/tic-tac-toe/

## Features

- **Vs Computer**: you play X. *Unbeatable* uses minimax, so the best you can do is draw. *Easy* plays its best move only 40% of the time.
- **2 Players**: take turns on the same screen.
- Score tally for wins and draws; the starting player alternates each round.
- Keyboard playable (Tab and Enter), light and dark themes, works on phones.

## Run locally

Open `index.html` in any modern browser.
